# 生物进化 Roguelike

像素风俯视角动作 Roguelike。玩家通过基因卡改变攻击方式与身体形态，组合不同 Build，完成进化冒险。

## 当前阶段

核心战斗、Build 与首轮 Roguelike 循环整合验证。

冲刺战斗、10 张基因卡、多路线进化、成长经济、实体商店、随机路线、事件与双 Boss 已经可玩。

## 开发原则

- 优先验证战斗手感和基因 Build。
- 系统保持模块化，内容采用数据驱动。
- 角色、敌人、技能、基因和进化使用独立数据资源。
- 新增普通基因不应要求修改战斗核心。

## 基础输入

- 移动：WASD
- 攻击：鼠标左键
- 冲刺：空格（带短暂无敌）
- 基因图鉴：C
- 开始房武器选择：走进左侧或右侧培养舱
- 开始房角色选择：先走进角色孵化舱
- 前往下一房间：N
- 奖励房选择基因：1 / 2 / 3（也可鼠标点击）
- 路线分叉选择：使用 WASD 走进左侧或右侧入口
- 结算后重新开始：R

## 当前可玩内容

- 测试竞技场
- 原始生命占位形态
- WASD 八方向移动
- 基于角色数据资源的移动速度
- 鼠标瞄准
- 按住鼠标左键连续发射基础子弹
- 空格冲刺、冲刺无敌、敌人攻击击退与受伤镜头震动
- 数据驱动的追踪实验体
- 敌人追踪玩家并在近距离停止
- 通用生命、受击区域与伤害系统
- 基础子弹造成 10 点伤害，实验体生命归零后死亡
- 伤害数字、受击闪白与轻微视觉位移
- 数据驱动的敌人死亡爆裂效果
- `GeneData → GeneEffect → AttackContext` 基因修改链
- 火焰基因通过 Data 修改伤害、弹速、大小、颜色和攻击标签
- 分裂基因一次攻击生成三枚散射子弹
- 火焰与分裂可同时装备，三枚子弹都会继承火焰属性
- 穿透基因让子弹最多连续命中三个目标
- 吸血基因回复实际伤害的 50%，爆炸基因命中造成范围伤害
- 新增加速、巨化、双生、剧毒与冰冻基因，原型池扩充至 10 张
- 剧毒造成持续伤害，冰冻会暂时降低敌人移动速度
- 分裂与剧毒组合进化为瘟疫母巢
- 火焰 + 分裂 + 爆炸会自动激活“炎爆流”
- 炎爆流让爆炸伤害翻倍，并将爆炸范围扩大 50%
- 装备火焰基因后，原始生命进化为火焰生命
- 激活炎爆流后，火焰生命进一步进化为炎龙
- 炎龙形态额外提升 20% 攻击伤害、15% 弹速和 15% 子弹体积
- 随机路线：开始房 → 教学战 → 基因奖励 → 随机战斗 → 事件 → 精英 → 基因商店 → 秘宝房 → Boss
- 每局路线带独立随机种子，相同种子可复现同一路线
- 遇到多个候选房间时会在场景中开启两个入口，玩家走入其中一个决定路线
- 废弃实验室事件提供三个实体实验舱：治疗、随机基因、高危突变
- 共生孵化室提供共生修复、营养恢复和寄生爆发选择
- 事件层通过两个实体入口提供不同事件，玩家可直接选择探索方向
- 事件、选项和效果使用独立 Data，可继续添加事件而不修改房间核心
- 数据驱动秘宝系统已接入攻击修改链
- 龙心只强化带有火焰标签的攻击：伤害提高 25%，体积提高 15%
- 裂变腺体只强化分裂攻击：伤害提高 15%、弹速提高 20%
- 精英战后进入秘宝房，走向两个实体祭坛选择一件秘宝
- 武器器官使用独立 Data，由开始房的两个实体培养舱选择
- 原生喷针：均衡、快速，基础伤害 10
- 重孢炮：射速较慢，弹体更大，基础伤害 18
- 开始房采用两步准备：先选择角色，再选择武器器官
- 原始生命：100 生命、120 移速的均衡角色
- 深渊生命：125 生命、105 移速的耐久角色，拥有独立基础形态
- 机械生命：85 生命、135 移速的高机动角色，拥有独立机械形态
- 开始房第三步通过实体共生舱选择孢子侍从或独行进化
- 孢子侍从会跟随、自动索敌攻击，并受分裂基因强化
- 首个正式 Boss“基因吞噬体”拥有地面预警攻击与半血狂噬阶段
- 第二 Boss“机械熔铸核心”拥有熔核标记与半血过载阶段，Boss 前通过两个实体入口选择挑战
- Boss 阶段、攻击冷却、范围、伤害与视觉均由独立 Data 资源配置
- 分裂路线：分裂基因进化为裂殖生命，弹体更小、更快
- 分裂与穿透组合进化为群巢母体，一次发射六枚穿透弹体
- 吸血路线：吸血基因进化为血囊生命，命中回复提高至 70%
- 吸血与爆炸组合进化为深渊吞噬者，扩大爆炸并提高至 80% 吸血
- 一次冒险依次穿越原生培养区、深渊实验区和机械铸巢区
- 区域地面、边界、环境装饰和强调色均由独立 RegionData 配置
- 正式启动入口包含像素风标题界面、开始游戏与退出选项
- 游戏内按 ESC 可暂停、继续或返回标题界面
- 正式 HUD 隐藏开发快捷键，并将 Build、生命和房间信息集中展示
- HUD 新增玩家血条、成长等级、基因精华、全局 Boss 血条和 Build/进化提示
- 首次进入冒险会显示操作引导，开始移动或攻击后自动收起
- 普通敌人拥有数据驱动的近战伤害、攻击距离和冷却
- 玩家受到敌人攻击时会闪烁反馈，普通战斗现在也可能导致失败
- 深渊区域加入孢子射手，会保持距离并发射可躲避的敌方弹体
- 敌方弹体使用独立阵营碰撞层，跨房间时由投射物容器统一清理
- 奖励房从尚未拥有的基因中随机展示三张，选择后才能前进
- 击杀敌人获得经验与基因精华，升级会逐步提高攻击伤害
- 实体基因商店可走进左右培养舱消费精华购买基因，也可从下方出口离开
- 基因图鉴按四个系列归档；首次见到后永久解锁描述，按 C 随时查看
- 新获得基因会显示所属系列，以及当前已经拥有的同系列关联卡
- 玩家、敌人与双 Boss 已接入像素图集动画，缺失贴图时自动回退程序化外观
- 三区域拥有统一风格的瓦片与环境参考图集，并预留 TileSet、背景和环境场景接口
- 攻击、冲刺、受击、死亡、进化和 Boss 阶段变化拥有数据驱动音效
- 原生、深渊、机械区域及 Boss 战拥有独立背景音乐；未指定音频文件时使用合成回退
- 美术通过 `ActorVisualData` / `RegionVisualData` 替换，音频通过 `AudioCueData` / `MusicTrackData` 替换
- 战斗、精英和 Boss 房必须清空敌人才能前进
- 玩家生命、基因、Fusion 和进化形态会跨房间保留
- 玩家死亡或击败 Boss 后显示本局结算，按 R 清空 Build 并生成新路线

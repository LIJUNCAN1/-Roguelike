# 生物进化 Roguelike

像素风俯视角动作 Roguelike。玩家通过基因卡改变攻击方式与身体形态，组合不同 Build，完成进化冒险。

## 当前阶段

阶段 3：Build Fusion 验证。

基础战斗 Demo、首批 5 张基因卡和第一个融合流派已经可玩。当前重点是验证基因组合是否能产生明显流派，尚未进入形态进化或 Roguelike 地牢开发。

## 开发原则

- 优先验证战斗手感和基因 Build。
- 系统保持模块化，内容采用数据驱动。
- 角色、敌人、技能、基因和进化使用独立数据资源。
- 新增普通基因不应要求修改战斗核心。

## 基础输入

- 移动：WASD
- 攻击：鼠标左键
- 火焰基因：G
- 分裂基因：H
- 穿透基因：J
- 吸血基因：K
- 爆炸基因：L
- 测试扣血：P

## 当前可玩内容

- 测试竞技场
- 原始生命占位形态
- WASD 八方向移动
- 基于角色数据资源的移动速度
- 鼠标瞄准
- 按住鼠标左键连续发射基础子弹
- 数据驱动的追踪实验体
- 敌人追踪玩家并在近距离停止
- 通用生命、受击区域与伤害系统
- 基础子弹造成 10 点伤害，实验体生命归零后死亡
- 伤害数字、受击闪白与轻微视觉位移
- 数据驱动的敌人死亡爆裂效果
- `GeneData → GeneEffect → AttackContext` 基因修改链
- 按 G 装备或卸下测试用火焰基因
- 火焰基因通过 Data 修改伤害、弹速、大小、颜色和攻击标签
- 按 H 装备或卸下分裂基因，一次攻击生成三枚散射子弹
- 火焰与分裂可同时装备，三枚子弹都会继承火焰属性
- 按 J 切换穿透基因，子弹最多连续命中三个目标
- 按 K 切换吸血基因，回复实际伤害的 50%
- 按 L 切换爆炸基因，命中造成范围伤害
- 按 P 扣除 30 点测试生命，用于观察吸血效果
- 火焰 + 分裂 + 爆炸会自动激活“炎爆流”
- 炎爆流让爆炸伤害翻倍，并将爆炸范围扩大 50%

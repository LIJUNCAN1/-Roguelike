# 生物进化 Roguelike

像素风俯视角动作 Roguelike。玩家通过基因卡改变攻击方式与身体形态，组合不同 Build，完成进化冒险。

## 当前阶段

阶段 0：Godot 4 项目准备。

当前只包含项目配置、输入映射、测试入口场景与模块化目录，不包含正式战斗玩法。

## 开发原则

- 优先验证战斗手感和基因 Build。
- 系统保持模块化，内容采用数据驱动。
- 角色、敌人、技能、基因和进化使用独立数据资源。
- 新增普通基因不应要求修改战斗核心。

## 基础输入

- 移动：WASD
- 攻击：鼠标左键

## 当前可玩内容

- 测试竞技场
- 原始生命占位形态
- WASD 八方向移动
- 基于角色数据资源的移动速度

# 生物进化 Roguelike

像素风俯视角动作 Roguelike。玩家通过基因卡改变攻击方式与身体形态，组合不同 Build，完成进化冒险。

## 当前阶段

阶段 7：秘宝系统验证。

基础战斗、首批 5 张基因卡、炎爆流、火焰进化路线、随机路线、实体路线分叉、奖励三选一和两个随机事件已经可玩。

## 开发原则

- 优先验证战斗手感和基因 Build。
- 系统保持模块化，内容采用数据驱动。
- 角色、敌人、技能、基因和进化使用独立数据资源。
- 新增普通基因不应要求修改战斗核心。

## 基础输入

- 移动：WASD
- 攻击：鼠标左键
- 火焰基因：G
- 分裂基因：H
- 穿透基因：J
- 吸血基因：K
- 爆炸基因：L
- 测试扣血：P
- 前往下一房间：N
- 奖励房选择基因：1 / 2 / 3（也可鼠标点击）
- 路线分叉选择：使用 WASD 走进左侧或右侧入口
- 结算后重新开始：R
- 测试龙心秘宝：B

## 当前可玩内容

- 测试竞技场
- 原始生命占位形态
- WASD 八方向移动
- 基于角色数据资源的移动速度
- 鼠标瞄准
- 按住鼠标左键连续发射基础子弹
- 数据驱动的追踪实验体
- 敌人追踪玩家并在近距离停止
- 通用生命、受击区域与伤害系统
- 基础子弹造成 10 点伤害，实验体生命归零后死亡
- 伤害数字、受击闪白与轻微视觉位移
- 数据驱动的敌人死亡爆裂效果
- `GeneData → GeneEffect → AttackContext` 基因修改链
- 按 G 装备或卸下测试用火焰基因
- 火焰基因通过 Data 修改伤害、弹速、大小、颜色和攻击标签
- 按 H 装备或卸下分裂基因，一次攻击生成三枚散射子弹
- 火焰与分裂可同时装备，三枚子弹都会继承火焰属性
- 按 J 切换穿透基因，子弹最多连续命中三个目标
- 按 K 切换吸血基因，回复实际伤害的 50%
- 按 L 切换爆炸基因，命中造成范围伤害
- 按 P 扣除 30 点测试生命，用于观察吸血效果
- 火焰 + 分裂 + 爆炸会自动激活“炎爆流”
- 炎爆流让爆炸伤害翻倍，并将爆炸范围扩大 50%
- 装备火焰基因后，原始生命进化为火焰生命
- 激活炎爆流后，火焰生命进一步进化为炎龙
- 炎龙形态额外提升 20% 攻击伤害、15% 弹速和 15% 子弹体积
- 随机路线：开始房 → 教学战 → 基因奖励 → 随机战斗 → 事件 → 精英 → 秘宝房 → Boss
- 每局路线带独立随机种子，相同种子可复现同一路线
- 遇到多个候选房间时会在场景中开启两个入口，玩家走入其中一个决定路线
- 废弃实验室事件提供三个实体实验舱：治疗、随机基因、高危突变
- 共生孵化室提供共生修复、营养恢复和寄生爆发选择
- 事件层通过两个实体入口提供不同事件，玩家可直接选择探索方向
- 事件、选项和效果使用独立 Data，可继续添加事件而不修改房间核心
- 数据驱动秘宝系统已接入攻击修改链
- 龙心只强化带有火焰标签的攻击：伤害提高 25%，体积提高 15%
- 裂变腺体只强化分裂攻击：伤害提高 15%、弹速提高 20%
- 精英战后进入秘宝房，走向两个实体祭坛选择一件秘宝
- 奖励房从尚未拥有的基因中随机展示三张，选择后才能前进
- 战斗、精英和 Boss 房必须清空敌人才能前进
- 玩家生命、基因、Fusion 和进化形态会跨房间保留
- 玩家死亡或击败 Boss 后显示本局结算，按 R 清空 Build 并生成新路线
